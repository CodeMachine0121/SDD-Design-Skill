# Proposal Format (Step 4)

Present the brief outline for confirmation using this structure:

```
**[Proposed Design Brief]** — awaiting confirmation

Goal: <one sentence — the user need this experience serves>

Target users: <role(s) and their context>

Experience goals: <the qualities the experience must have — e.g. fast, low-friction, trustworthy>

User flow (conceptual):
- <step / decision point>
- <step / decision point>

Out of scope:
- <item>

Open decisions (for ui-spec to resolve):
- <item — e.g. a layout or screen-structure question deliberately deferred>

Confirmed scenarios: <N> across <M> flows/rules

Will write to: .sdd/{yyyy-MM-dd}-{feature-slug}/DESIGN-BRIEF.md

Type "Confirm" or "Go" to generate the file.
```
